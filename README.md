# HolyBibleBook.org

A free, faith-based Bible web app for reading, studying, and learning Scripture, with multiple translations, study games, and a personal journal in one place.

**Live site:** https://holybiblebook.org

![HolyBibleBook.org homepage](screenshot.png)

## About

HolyBibleBook.org is a Progressive Web App (PWA) I founded and built to make Bible study more accessible and engaging. It works in any browser and can be installed on a phone or desktop like a native app. An Android version is being prepared for the Google Play Store.

## Features

- **Multiple translations:** KJV, BBE, Darby, ESV, AMP, NASB, NKJV, NLT, plus 21+ international translations
- **Study games:**
  - *Scripture Blaster*: an arcade-style shooter that reinforces verses
  - *Scripture Blocks*: a puzzle game built around Scripture
  - Bible quizzes, trivia, and flashcards
- **Bible Journal:** write and save personal notes and reflections
- **Verse of the Day:** a daily verse with one-tap sharing
- **Installable PWA:** add it to your home screen on mobile or desktop
- **Responsive design:** works on phone, tablet, and desktop

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)
- PWA technologies (web app manifest, service worker)
- Hosted on Netlify
- Packaged for Android with PWABuilder
